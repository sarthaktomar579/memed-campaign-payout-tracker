# Meme'd Campaign Payout Tracker 🚀

A full-stack creator marketplace platform built for Meme'd (WLDD SDE-I Assignment).

Brands create influencer campaigns with milestone ladders, and creators submit posts to track views and earn payouts based on the highest milestone achieved—strictly bounded by campaign budgets.

## 🏗️ Repository Architecture
- `/backend`: Node.js, Express, TypeScript, MongoDB (Mongoose), Jest, Redis caching
- `/frontend`: Next.js (App Router), TypeScript, Tailwind CSS, Modern UI
